## 🚀 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ashwinisk2208-dot/my-portfolio.git
   cd my-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
